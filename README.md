# Emon Vai Marketplace

GitHub Pages-এর জন্য তৈরি static website.

ফাইল:
- index.html
- style.css
- app.js

GitHub:
1. একটি repository তৈরি করুন।
2. এই ৩টি ফাইল upload করুন।
3. Settings → Pages → Deploy from branch → main → /root নির্বাচন করুন।

নোট: আসল Gmail/Phone OTP login ও Admin database চালাতে Firebase Authentication/Firestore-এর মতো backend service লাগবে। GitHub Pages একা database বা OTP service নয়।
